## 🏛️ Theme & Architectural Ideation

The 30th edition of Techfest is themed **"An Aetherial Renaissance"**, symbolizing an intellectual awakening where classical symmetries and Da Vincian inquiry converge with the modern frontier of deep-tech, artificial intelligence, autonomous robotics, and aerospace.

### Zero-3D Constraint Architecture

To satisfy the strict constraint of **No 3D Assets** while delivering a visually arresting, high-tech experience:

1. **Interactive 2D Mathematical Astrolabe**: Custom vector geometry featuring rotating concentric rings, cardinal coordinate axes, and runic glyphs rendered purely in 2D with CSS keyframe interpolation.

2. **Dynamic 2D Canvas Flux Engine**: A lightweight HTML5 Canvas engine featuring mouse proximity attraction, dynamic vector connections, and three selectable modes (*Neural Web*, *Celestial Orbit*, and *Quantum Warp*).

3. **In-Browser Web Audio Synthesizer**: Uses the Web Audio API to synthesize ambient sci-fi drones, high-frequency interface blips, and fanfare chords on demand without external audio files.

## ⚡ Core Feature Modules

1. **Hero & Real-Time Countdown**: Live countdown clock ticking down to the December 16, 2026 inauguration at IIT Bombay.

2. **Telemetry Counter Strip**: Highlights 180K+ footfall, 35K+ competitors, 2,500+ colleges reached, and ₹50L+ prize pool.

## 🛠️ Local Execution & GitHub Setup

1. **Run Locally**:
   Double-click `index.html` to run in any modern web browser. Zero dependencies or servers required.

2. **Push to GitHub**:

   ```
   git init
   git add .
   git commit -m "feat: Techfest 2026 Landing Page"
   git branch -M main
   git remote add origin https://github.com/mohdaqib1119/techfest-2026-landing-page.git
   git push -u origin main
   
   ```

3. **Activate GitHub Pages**:
   In GitHub, go to **Settings > Pages > Build and deployment > Deploy from a branch** (`main` / root).
